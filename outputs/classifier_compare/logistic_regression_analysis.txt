Interpretation notes
--------------------
- Logistic regression is a linear classifier, so it tests whether the current feature set supports reasonably separable class regions with linear decision boundaries.
- If this performs similarly to or better than KNN, the features are carrying class information in a globally organized way rather than only through local neighbourhood structure.
- If this underperforms KNN, then local clusters matter more than a single global boundary.
- Large positive or negative class weights indicate which features the model leans on most strongly for that class, but the sign should be interpreted relative to all other features after standardization.
